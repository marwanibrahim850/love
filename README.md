# Blue Heart

Static website version of the original Pygame animation. It needs no Node.js, React, Next.js, or Tailwind.

## Publish with GitHub Pages

1. Create a GitHub repository and upload these files to its `main` branch.
2. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Push to `main`. The included workflow publishes the site automatically.
4. The live URL will be: `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

The button starts the included music after a visitor taps it; browsers block automatic sound playback.
